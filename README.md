# Harin M. Mohan — Modern Academic Portfolio (Version 3)

A contemporary academic portfolio with a horizontal navigation bar, full-width blue/cyan hero, large portrait area, clean editorial sections and responsive mobile navigation.

## Files
- `index.html` — page content
- `styles.css` — modern visual design and responsive layout
- `script.js` — mobile navigation and dynamic copyright year
- `PUBLISHING_GUIDE.md` — publishing instructions

## Preview
Extract the ZIP and open `index.html` in a browser.

## Personalise before publishing
1. Replace the hero `photo-placeholder` div with:
   `<img class="profile-photo" src="images/harin-profile.jpg" alt="Dr. Harin M. Mohan">`
2. Add this CSS: `.profile-photo{width:100%;height:100%;object-fit:cover;border-radius:7px;display:block}`
3. Create an `images` folder and add your photo as `harin-profile.jpg`.
4. Replace `YOUR_EMAIL@example.com` and the generic LinkedIn, Google Scholar and ORCID URLs with your actual profile links.
5. Add verified publication titles, DOI links, patent numbers, awards, dates and full education details.
6. Replace any text that needs updating to reflect current role and project status.

## Google Sites
Google Sites cannot upload and run a complete custom HTML/CSS/JS website as a native site. Host the coded site using GitHub Pages or Netlify, then embed its URL in Google Sites via Insert → Embed → By URL, or use it as your standalone website. See `PUBLISHING_GUIDE.md`.
