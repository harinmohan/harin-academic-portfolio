# Publishing guide

## Preview locally
Extract the ZIP and open `index.html` in Chrome, Edge or Firefox.

## Host on GitHub Pages
1. Create a GitHub repository (for example `harin-academic-portfolio`).
2. Upload `index.html`, `styles.css`, `script.js` and your `images` folder to the repository root.
3. Open Settings → Pages.
4. Select Deploy from a branch, choose `main` and `/ (root)`, then Save.
5. GitHub Pages will provide a public URL. Test it on desktop and mobile.

## Host on Netlify
Create a Netlify account, then drag the extracted website folder into the manual deploy area. Netlify will provide a public URL.

## Use with Google Sites
Google Sites cannot run the full uploaded website as its native theme. To display the hosted website inside a Google Sites page:
1. Open your Google Site.
2. Choose Insert → Embed → By URL.
3. Paste your GitHub Pages or Netlify URL.
4. Insert and resize the embed area.
Alternatively, recreate the page structure using native Google Sites sections and use the coded website as a visual reference.

## Before going public
Replace the photo, email and social URLs. Verify academic dates, qualification details, publications, patents and awards. Do not publish placeholders.
